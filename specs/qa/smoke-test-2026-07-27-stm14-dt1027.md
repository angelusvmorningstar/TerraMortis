## A. STM-14 — audited ad-hoc bonus (`/admin`, ST login)

Source: story 1034.1 Testing section + QA gate 1034.1 (Ma'at flagged AC1/AC3/AC4/AC5 as browser-only).

- [ ] **A1 (AC1) Apply flow.** On a rendered character sheet, apply an ad-hoc situational bonus to an attribute (e.g. +2 Strength). A reason prompt appears; an empty reason is blocked (reason required).
- [ ] **A2 (AC1) Skill path.** Repeat on a skill (e.g. +1 Brawl) — same reason prompt, same result.
- [ ] **A3 (AC3) Overlay applies.** After confirming, the attribute/skill total reflects the delta on the sheet, and the st-mod marker chip appears next to it.
- [ ] **A4 (AC3 / #1040 — KEY) Reason popover.** Click the marker chip. Does the popover open and show Base / Adjustment / Final + the reason? **This is the open question in #1040** — the popover resolves the character via never-assigned `window.chars`/`editIdx` and may silent-no-op on the ST sheet. - [ ] **A5 (AC2) No doc write.** The delta lives only in the overlay. Confirm the persisted character document's `attributes[X].bonus` is unchanged (via a fresh reload — the bonus should reapply from st_mods, not from the doc). If you can inspect the API/DB, `attributes[X].bonus` should still be its pre-existing value, not the new total.
- [ ] **A6 (AC1) Fresh-boot persistence.** Reload the page. The applied bonus still shows (reapplied via `applyOverlayToAll` from st_mods, not a doc write).
- [ ] **A7 (AC4) Toggle lifecycle.** Open the ST-mods panel for the character; find the new bonus mod in the active list; deactivate it. The sheet total drops back; an audit `deactivated` event is recorded. Reactivate → total returns.
- [ ] **A8 (AC5) Editor controls retired.** Enter edit mode on the sheet. The old `+○ / −○` bonus controls are GONE. Base-dot editing still works (click a dot to raise/lower the base rating — `clickAttrDot`/`clickSkillDot` unaffected). Exit edit mode → overlay reapplies.
- [ ] **A9 (AC7) Styling.** New reason modal + apply button look consistent (gold accent), no broken/unstyled elements, works in both light (Parchment) and dark themes.
