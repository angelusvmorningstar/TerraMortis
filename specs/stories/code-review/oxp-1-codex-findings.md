## High

- **[Pass 1] The purported ISO-date guard accepts impossible dates and malformed timestamps.** Severity: High. File: `server/schemas/office_seat.schema.js:76`; mirrored in `server/scripts/seed-office-seats.mjs:109`. Trigger: supply Rene's required override as `2026-99-99` (or a syntactically matching timestamp such as `2026-02-21T+++`). Observable consequence: `buildSeatDocs` accepts the value and an `--apply` run can persist it to the live collection even though downstream date arithmetic can produce `NaN`, exactly the silent bad-XP outcome the guard says it prevents; the schema accepts the same bad value. The tests cover prose (`21 February 2026`) but no calendar-invalid matching value. Confidence: High (direct regex analysis; no script or database invocation).

## Medium

Confidence: High (direct control-flow analysis).
