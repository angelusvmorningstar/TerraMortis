MOCKUP — GDX-9 Single-Scroll Phone Sheet (#990)
New in this story: the pinned track strip and the jump-nav chip row below. Everything under them (Info → Stats → Skills → Powers) reuses existing sheet markup, concatenated into one scroll instead of four separate tab destinations.
Locked-decision callout: when this mode is on, the bottom nav's separate Stats/Skills/Powers/Info buttons collapse into a single "Sheet" entry — the jump-chips replace tab-switching for those four, so there is exactly one way to navigate between them (AC2: no duplicate nav layers). Correction from the first draft: "the full trackers" the pinned strip taps through to are NOT a separate Status tab (that tab is City/Covenant/ Clan standing, unrelated) — they're sheet.js's own sh-tracker-block, which already lives inside the Stats section content itself. So tapping the strip just jumps to Stats, same as the Stats chip; the strip is a compact glance-and-jump for the same tracker, not a pointer to a different destination. Desktop's existing concatenated view (sheet.js:755) is untouched.
