Two corrections from the previous version. First: that pass showed Lashing Out and Humanity Breaking Point using the app's OTHER real modal — the bottom sheet the Character/ Discipline picker uses (#panel/#panel-overlay). The recovered code shows all five choice specials sharing a DIFFERENT real component instead — the wizard-style .fb-modal family, reused from the app's own Free Build picker. Fixed throughout, and the three specials missing before are added: Clash of Wills, Resist Blood Bond, Detecting Blood Sympathy. Second: Riding the Wave is not its own roll. The live app's own char-pools.js lists it as a separate Wits+Composure tile, but that's a rules error — the recovered build's own server.mjs only ever builds a single "Resisting Frenzy" special, and the core rule (p.103–104) has Riding the Wave as a Willpower spend made ABOUT a frenzy already triggered by a failed resistance roll, not a pool of its own. Corrected below: Frenzy Resistance is the one tile, with Riding the Wave named as the option that follows a failed roll.

Where each piece comes from, precisely

  • Skills / Disciplines / Special accordions — the collapse mechanism is real (char-pools.js), but today it is ONE toggle over Skills+Disciplines combined, and Special ("Vampire Mechanics") is a fixed heading that never collapses. Splitting all three into independent peers is new work proposed here.
  • Frenzy Resistance — already live as an immediate-roll tile, no pop-up. Its subtitle now names Riding the Wave as the follow-up option on a failed roll — the live app currently lists Riding the Wave as a wrongly-separate Wits+Composure tile of its own, which this mockup does not carry forward.
  • Surprise / Perception — NOT live. Also an immediate-roll tile with no pop-up in the recovered build; just not ported into the real app yet.
  • Lashing Out, Resist Blood Bond — already live today, each its own .fb-modal wizard.
  • Clash of Wills — the real app has a version today (limitation: can't pick the opposing Discipline itself). The recovered build's own two-step version (power, then a duration ladder) is not live.
  • Detecting Blood Sympathy — NOT live in any form. Built and working only in the recovered build.
  • Humanity Breaking Point, player-side picker — NOT live. What shipped (gdx.12) has the player submit blind and the ST choose the level in the admin Approval Queue. This mockup shows the player-side flow you built afterwards — see the callout below.
  • Rules explanation box — the data is already computed and passed to every pool today; only the rendering is new.
  • Remembered modifier chips — already shipped (rlv.7), only relocated here.
  • Again segment, anchor number, Vitae/WP resource cards — already shipped, carried forward unchanged.
